How-to

Publish a clip for the first time

Connect accounts once in Settings. On a clip, pick the platforms. Posts stay private by default so you can try safely. These steps can be updated without shipping a new build.

01 · Open Settings → Publish

  1. 01

    Open Settings from the top right and choose Publish. Overseas accounts and Bilibili are on the same page.

  2. 02

    Video is still processed on your machine. Only the finished file is uploaded: overseas platforms go through Upload-Post; Bilibili uses a cookie saved on this computer.

02 · Overseas platforms: Upload-Post

  1. 01

    Open app.upload-post.com and create an account.

  2. 02

    In Manage Users, create a profile and connect the social accounts you want to post to.

  3. 03

    Create a key in API Keys, paste it into AutoClip, and save to verify.

  4. 04

    The publish page defaults to Only me: TikTok uses SELF_ONLY, YouTube uses private. Public posts appear on the account immediately.

03 · Bilibili: three cookies

  1. 01

    In Chrome or Edge, open bilibili.com and sign in.

  2. 02

    Press F12 (on a Mac, ⌥⌘I) to open Developer Tools, then open Application.

  3. 03

    Cookies → https://www.bilibili.com. Copy the values named SESSDATA, bili_jct, and DedeUserID.

  4. 04

    Paste them as one line: SESSDATA=…; bili_jct=…; DedeUserID=…, then save and verify in Settings.

It stays on this computer

The cookie is saved only on this machine. It is not sent to the repository or website. If it expires or you switch accounts, sign in again and copy the three fields.

04 · Publish from a clip

  1. 01

    Open a project, select Publish on a clip, choose platforms, leave visibility set to Only me, then start publishing.

  2. 02

    Generate a cover with one click. If image generation fails or no model is configured, a frame is used and publishing continues.

  3. 03

    Schedule Bilibili posts at least two hours from now. The aspect ratio follows the accounts: render 9:16 if any account is vertical; use landscape for Bilibili alone.

FAQ

What if the cookie is rejected?

Sign in to Bilibili again and copy the three fields from Application → Cookies. Do not paste a whole request header. A missing field fails the check.

No profile yet?

Create a profile in Upload-Post, connect the accounts you want to publish to, then refresh accounts in AutoClip.

Does a failed cover block publishing?

No. If generation fails or has not finished, the post uses a frame capture and the flow continues.
