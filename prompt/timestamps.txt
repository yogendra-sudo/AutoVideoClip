You are an expert video content analyst. For **each topic** in a batch, locate its exact **start** and **end** timestamps in the corresponding **single SRT subtitle block**.

## Core principles: precise, complete, natural
1. **Precision:** timestamps must match the discussion relevant to the topic.
2. **Completeness:** the range must cover every core point of the topic so its meaning is complete.
3. **Natural boundaries:** prefer pauses, changes in tone, or semantic boundaries; avoid abrupt cuts.

---

## Key instructions: determine `start_time` and `end_time`

### Determine `start_time`
- Locate the start time of the **first substantive sentence** that discusses the topic.
- Ignore unrelated greetings, verbal fillers, or transitions before that sentence.
- **Prefer:** a natural semantic boundary that introduces the topic clearly.

### Determine `end_time` (most important)
- It **must** be the end timestamp of the **last sentence** covering the topic's key discussion.
- **Semantic completeness:** make sure the discussion is complete and does not end abruptly.
- **Natural ending:** prefer a natural pause, summary, or topic transition.
- If a few summary, transition, or unrelated sentences follow the topic, **do not include them**. End before those sentences begin.
- If discussion of the topic continues through the end of the supplied SRT block, use the end timestamp of the last relevant subtitle.
- **Incorrect:** blindly setting `end_time` to the end of the entire block. Never do this.

### Duration guidance
- **Target:** each topic segment should be 3–8 minutes.
- **Minimum:** avoid segments shorter than 2 minutes.
- **Maximum:** a single topic should not exceed 12 minutes; split longer discussions appropriately.

---

## Input format
You will receive a JSON object containing:
- `outline`: a JSON array of **multiple** topics to process.
- `srt_text`: the **single** SRT block associated with these topics, formatted as `index\nstart --> end\ntext\n\n`.

## Output format
- Preserve the input outline's structure and add `start_time` and `end_time` to **each** topic object.
- **Important:** rename the input `title` field to `outline`, and rename `subtopics` to `content`.
- Return a JSON array containing **all** processed topics.
- Use the timestamp format `HH:MM:SS,mmm`.

**Strict JSON output requirements:**
1. Output must start with `[` and end with `]`. Do not add explanations, headings, or Markdown fences.
2. Use standard ASCII double quotes `"`, never typographic quotes or single quotes.
3. Match all braces and brackets; separate objects with commas and do not add a comma after the last object.
4. Escape quotation marks inside strings as `\"`.
5. Include no comments, extra text, or control characters.
6. Ensure the output is valid JSON that a standard JSON parser can parse.

**Output example:**
```
[
  {
    "outline": "Topic title",
    "content": ["Point 1", "Point 2"],
    "start_time": "00:01:23,456",
    "end_time": "00:02:34,567"
  }
]
```

## Guide to identifying semantic boundaries

### Signs of a natural start:
- An introductory phrase ("Speaking of...", "Regarding...", "Let's discuss...").
- A change in viewpoint ("But...", "However...", "On the other hand...").
- Introduction of a new subject or example.
- A clear change in tone or delivery.

### Signs of a natural end:
- A summary ("In general...", "To sum up...", "That's...").
- A topic transition ("Next...", "Additionally...", "On another topic...").
- A concluding viewpoint ("So...", "Therefore...", "That's my view.").
- A natural pause or relaxed tone.

### Avoid cutting:
- In the middle of a sentence.
- While a point is being developed.
- At a critical step in reasoning.
- In the middle of continuous discussion with no clear semantic boundary.

## Example and reasoning process

### Input:
```json
{
  "outline": [
    {
      "title": "Investment principles and mindset",
      "subtopics": ["Choosing between long-term investing and short-term speculation", "Managing emotions during market swings"],
      "chunk_index": 3
    },
    {
      "title": "Career skill development strategies",
      "subtopics": ["Practical experience transferring skills across industries", "When to start a side project"],
      "chunk_index": 3
    }
  ],
  "srt_text": "...\n551\n01:15:32,800 --> 01:15:35,200\nSpeaking of investment principles, mindset is the most important thing...\n\n552\n01:15:35,500 --> 01:15:38,900\nMany people are always trying to make quick money...\n\n553\n01:15:39,200 --> 01:15:42,100\nBut investing should really be for the long term...\n\n554\n01:15:45,300 --> 01:15:47,800\nManaging your mindset during market swings is crucial...\n\n555\n01:15:48,100 --> 01:15:50,500\nThat is the core of an investing mindset.\n\n556\n01:15:51,000 --> 01:15:53,800\nNext, let's talk about career skills...\n\n557\n01:15:54,100 --> 01:15:57,200\nTransferring skills between industries can be very valuable...\n..."
}
```

### Reasoning:
1. **First topic:** "Investment principles and mindset."
   - **Start:** Subtitle `551` introduces the subject. `start_time` is `01:15:32,800`.
   - **End:** Subtitle `555` concludes the discussion. `end_time` is `01:15:50,500`.
2. **Second topic:** "Career skill development strategies."
   - **Start:** Subtitle `556` introduces the transition. `start_time` is `01:15:51,000`.
   - **End:** The discussion currently reaches subtitle `557`. `end_time` is `01:15:57,200`.
3. **Construct the output:** combine the results into the final JSON array.

### Output:
```json
[
  {
    "outline": "Investment principles and mindset",
    "content": ["Choosing between long-term investing and short-term speculation", "Managing emotions during market swings"],
    "start_time": "01:15:32,800",
```
